# GO Operation

Última atualização: Out. 30, 2025.

---

---

## Descrição

Seção destinada aos **Gerentes Operacionais** para o gerenciamento e remoção de mídias promocionais (combos/ofertas) programadas nos cinemas sob sua responsabilidade.

Através desta tela, o usuário pode selecionar todos os cinemas atrelados, visualizar todas as mídias promocionais programadas e removê-las da exibição.

Além disso, a tela fornece um histórico de exclusões, permitindo rastrear quando uma mídia foi removida, por qual usuário e em qual player.

## 1. GO Operation

<img src="imported/shared/d1c65d6fc2b60b84.png" alt="image-20251030-171851.png"/>

#### **1. Botão “Selecionar Cinema”**

Abre a janela para seleção do cinema desejado.
Somente após selecionar um cinema a listagem de mídias será exibida.

#### **2. Campo de busca (pesquisa)**

Permite buscar mídias específicas dentro do cinema selecionado, utilizando palavras-chave como nome da mídia.

#### **3. Tabela — Mídias Programadas**

Lista as mídias promocionais vinculadas ao cinema selecionado, com as seguintes colunas:

| Coluna | Função |
| --- | --- |
| Nome da Mídia | Exibe o nome do combo/mídia promocional |
| Formato | Tipo de arquivo (Ex.: MP4, JPG, WEBM) |
| Duração | Tempo de exibição do conteúdo |
| Data de Início | Quando a mídia começa a ser exibida |
| Data Final | Quando a mídia deixa de ser exibida |
| Pré-visualização | Opção para visualizar o conteúdo da mídia |

Até selecionar algum cinema, a mensagem será exibida:
**“Selecione primeiro o cinema para visualizar as mídias”**

#### **4. Seção — Histórico de Remoções**

Tabela de registro das mídias removidas pelos gestores.
Contém as seguintes colunas:

| Coluna | Função |
| --- | --- |
| Nome da Mídia | Nome da mídia removida |
| Cinema | Cinema onde foi removida |
| playerName | Nome do player |
| Hostname | Identificação do player |
| Data de Remoção | Data e horário da ação |
| Excluído por | Usuário responsável pela remoção |
| Status | Status da operação |

Quando não há registros:

**“Nenhum histórico disponível”**
